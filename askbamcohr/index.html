How you signed in

This app uses the OAuth 2.0 authorization code flow with PKCE, the standard for single-page apps.

  1. You chose Sign in. The app made a one-time PKCE secret and sent you to .
  2. Entra ID checked you. Your password, MFA and any Conditional Access policies ran here, not in this app.
  3. Entra sent you back to the registered redirect URI with a short-lived authorization code.
  4. The app traded the code for tokens. It proved it started the sign-in with the PKCE secret and got an ID token and an access token.
  5. The app called Microsoft Graph with the access token (scope User.Read) to fill in your badge.
